# 라운지엑스 경영관리 루프

관리회계대장(`라운지엑스_관리회계대장_2026_v2`)의 결론을 **경영관리 루프 5단계**로 재구성한 정적 사이트입니다.
GitHub Pages에 그대로 배포됩니다. 빌드 과정도 외부 라이브러리도 없습니다.

기준: **2026-09-23 · 실적 1~8월**

## 이 사이트가 하려는 것

> 목표를 명확히 하고 → 현재 스코어를 인식하고 → 무엇이 가장 문제인지 공유하고 →
> 그 문제를 풀 전략과제를 세우고 → 실행관리로 지표를 개선한다.

이 루프를 경영진부터 실무진까지 같은 순서로 돌기 위한 도구입니다.
지표를 나열하는 대시보드가 아니라, **결정을 내리기 위한 화면**입니다.

## 화면 구성 — 20페이지 / 6그룹

| 단계 | 페이지 |

| ② CSF·KPI 수립 | F&B 지표 체계와 측정 상태 · 세부사업별 CSF와 KPI · **점포 손익분기 배수** · 가맹 개시 게이트 9개 |

주소는 `#/goal`, `#/gap` 처럼 해시로 구분되므로 특정 페이지를 북마크하거나 링크로 공유할 수 있습니다.

### 세부사업 분류

모든 표·차트가 이 단위로만 쪼개집니다.

- **매장운영** — 유인직영 · 무인직영 · 투자모델
- **식자재유통** — 상품(B2B 원부자재) · 제품(로스터리)
- **가맹사업** — 미개시

'직영매장', '무인매장' 같은 상위 묶음은 세 모델의 손익 구조가 전혀 달라 평균이 왜곡되므로 쓰지 않습니다.

### 드릴다운

점선 밑줄이 그어진 파란 단어를 누르면 상세 패널이 열립니다. 현재 10개 —
매출원가 · 판관비 · 별도 추가비용 · 기계렌탈료 · 위탁수수료 · 위탁운영수수료 ·
감가상각비 · 건물관리비 · 원재료원가 · 로봇·자산 부담.

항목을 추가하려면 `data2.js` 의 `LX.drill` 에 키를 하나 넣으면 됩니다.
본문에서 그 단어가 자동으로 버튼이 됩니다.

## 파일 구조

```
index.html    껍데기 (상단바 · 사이드바 · 본문 틀). 내용은 JS가 채웁니다
ledger.css    스타일
ledger.js     라우터 + 렌더러 · 도넛/꺾은선/막대/히트맵 · 드릴다운 (의존성 없음)
data.js       ★ 루프 5단계 데이터. 매달 이 파일을 고칩니다
data2.js      ★ 상세 숫자 (사업별 손익계산서 · 점포별 · 드릴 설명)
README.md     이 문서
```

차트는 외부 라이브러리 없이 Canvas로 직접 그립니다. 인터넷이 막힌 환경에서도 열립니다.

## 배포 방법

1. GitHub 저장소 루트에 파일 다섯 개를 올립니다.

```bash
cd lx-ledger-site
git add .
git commit -m "경영관리 루프 5단계로 재구성 (2026-09-22 기준)"
git push
```

2. **Settings → Pages** → Source `Deploy from a branch`, Branch `main` / `/ (root)`.
3. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

### 화면이 안 바뀌면

`index.html` 의 `?v=20260923a` 가 캐시 무효화용입니다. 파일을 고칠 때마다 이 값을 올리십시오.
그래도 옛 화면이 보이면 `Ctrl+Shift+R`(Mac은 `Cmd+Shift+R`)로 강력 새로고침합니다.

### 비공개로 두려면

관리회계 수치가 들어 있으므로 공개 저장소로 올리면 누구나 볼 수 있습니다.
GitHub Pages는 Free 플랜에서 Private 저장소를 지원하지 않습니다. 선택지는 셋입니다.

- 조직 GitHub Team/Enterprise 플랜에서 Private Pages 사용
- 사내 파일서버나 구글 드라이브에 폴더째 올리고 `index.html` 을 여는 방식
- 숫자를 지우고 구조만 공개

## 설계 규칙

- **원인 없는 과제는 올리지 않습니다.** ④의 과제는 전부 ③에서 특정한 원인 세 개 중 하나에 묶여 있습니다.
- **과제에는 기대효과 금액과 산출 근거를 반드시 붙입니다.** 금액이 없으면 우선순위를 정할 수 없습니다.
- **측정되는 지표와 측정되지 않는 지표를 구분해 표시합니다.** 빨간 점이 붙은 지표는 아직 수집 체계가 없습니다.
- **baseline은 수식이 아니라 고정값으로 적습니다.** 실시간 수식은 과거가 계속 바뀌어 효과 검증이 불가능합니다.
- **경영진과 실무진의 진입점을 나눕니다.** 같은 화면을 다 보면 둘 다 안 봅니다. `⑤ 루프 운영 규칙` 에 역할별 페이지를 명시했습니다.
- **확정된 숫자와 미확정 숫자를 섹션으로 분리합니다.** 부록 `숫자 신뢰도`.
