# 라운지엑스 관리회계 포털

관리회계대장(`라운지엑스_관리회계대장_2026_v2`)의 내용을 한 페이지로 보여 주는 정적 사이트입니다.
GitHub Pages로 그대로 배포됩니다. 빌드 과정이나 외부 라이브러리가 없습니다.

기준: **2026-09-22 · 실적 1~8월 누계**

## 파일 구조

```
index.html    껍데기 (상단바 · 사이드바 · 본문 틀). 내용은 JS가 채웁니다
ledger.css    스타일
ledger.js     라우터 + 렌더러 · 도넛 차트 · 히트맵 · 드릴다운 (의존성 없음)
data.js       ★ 요약 숫자. 매달 이 파일을 고칩니다
data2.js      ★ 상세 숫자 (사업별 손익계산서 · 점포별 · 드릴 설명)
README.md     이 문서
```

차트는 외부 라이브러리 없이 Canvas로 직접 그립니다. 인터넷이 막힌 환경에서도 열립니다.

### 드릴다운

점선 밑줄이 그어진 파란 단어를 누르면 상세 패널이 열립니다. 예를 들어 비용 구성 차트의
**매출원가**를 누르면 사업별 구성과 비중이, **기계렌탈료**를 누르면 월별 추이와 2.9배 상승
경위가 나옵니다. 현재 드릴 항목은 9개입니다 — 매출원가 · 판관비 · 별도 추가비용 ·
기계렌탈료 · 위탁수수료 · 위탁운영수수료 · 감가상각비 · 건물관리비 · 원재료원가.

드릴 항목을 추가하려면 `data2.js` 의 `LX.drill` 에 키를 하나 넣으면 됩니다.
본문에서 그 단어가 자동으로 버튼이 됩니다.

## 배포 방법

1. GitHub에서 새 저장소를 만듭니다. 예: `lx-ledger`
2. 이 폴더의 파일 다섯 개를 저장소 루트에 올립니다.

```bash
cd lx-ledger-site
git init
git add .
git commit -m "라운지엑스 관리회계 포털 초판 (2026-09-22 기준)"
git branch -M main
git remote add origin https://github.com/<계정>/<저장소>.git
git push -u origin main
```

3. 저장소 → **Settings → Pages** → Source 를 `Deploy from a branch`,
   Branch 를 `main` / `/ (root)` 로 지정하고 저장합니다.
4. 1~2분 뒤 `https://<계정>.github.io/<저장소>/` 에서 열립니다.

### 비공개로 두려면

관리회계 수치가 들어 있으므로 공개 저장소로 올리면 누구나 볼 수 있습니다.
GitHub Pages는 Free 플랜에서 Private 저장소를 지원하지 않습니다. 선택지는 셋입니다.

- 조직 GitHub Team/Enterprise 플랜에서 Private Pages 사용
- 사내 파일서버나 구글 드라이브에 폴더째 올리고 `index.html` 을 여는 방식
- 숫자를 지우고 구조만 공개

## 매달 갱신하는 법

월 마감이 끝나면 `data.js` 만 고칩니다. HTML과 JS는 건드리지 않습니다.

1. `meta.asOf`, `meta.periodLabel`, `meta.baseMonth` 를 새 기준월로 바꿉니다.
2. `headline` — 30_대시보드 6~10행의 누계 값
3. `exceptions` — 30_대시보드 37~46행의 현재값과 판정
4. `landing` — 45_계획대실적 52~56행
5. `segments` / `costMix` — 30_대시보드 14~18행, 249~252행
6. `gap` — 45_계획대실적 7행과 11~18행
7. `breakdown` — 46_원인분해 §B, §B-3, §C, §D
8. `storeMatrix` — 46_원인분해 §B-2 (36~47행)
9. `actions` — 40_이슈관리 O~S열
10. `targets` — 44_프로젝션엔진 §D, §E

숫자는 **원 단위 정수**, 비율은 **소수**(0.55 = 55%)로 넣습니다.
화면에 억/만원 표기는 자동으로 변환됩니다.

## 만든 규칙

- 예외보고를 맨 앞에 둡니다. 모든 지표를 훑는 화면이 아니라 기준을 벗어난 것만 보는 화면입니다.
- 착지 전망을 누계 실적보다 위에 둡니다. 회의에서 결정을 가르는 것은 누계가 아니라 착지입니다.
- 원인 분해는 금액과 비율을 함께 보여 줍니다. 금액만으로는 점포 간 비교가 되지 않습니다.
- 과제에는 반드시 기대효과 금액과 산출 근거를 붙입니다. 금액이 없는 과제는 목표 간격과 연결되지 않습니다.
- 확정된 숫자와 확정되지 않은 숫자를 섹션으로 구분합니다.
